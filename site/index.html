v4.0 Core Evolution

The 2-Checkpoint Transversal Architecture

Instead of fragmented, per-phase reviews, AI-SDLC v4 consolidates verification into two high-leverage gates executed in parallel by polymorphic audit and adversarial agents.

CHECKPOINT 1 Pre-Implementation Freeze

Design & Specification Audit

Validates that specs, threat models, architecture, and task lists are sound, minimal, and battle-tested before writing production code.

🔍 agent-auditor

Verifies strict YAGNI, detects overengineering, ensures JSON Schema compliance and checks bidirectional upstream citations.

🗡️ agent-adversary

Attempts to break requirements: constructs STRIDE edge-case abuse attacks, missing boundary conditions, and conflicting rules.

CHECKPOINT 2 Pre-PR / Pre-Merge Freeze

Implementation & Gate Verification

Audits the working tree and pull request diff for Clean Code, AST quality policies, regression security vulnerabilities, and task rework.

🔍 agent-auditor

Validates AST thresholds (CC ≤ 10, MI ≥ 50), SOLID principles, test coverage, and ensures zero forbidden dependencies or copyleft licenses.

🗡️ agent-adversary

Runs mutation attacks, tests bypasses on authorization and input validation, and verifies that zero secrets leak into git history.

Topology & Observability

Streamlined 2-Tier Git & Task Rework KPIs

Eliminate branch friction without sacrificing traceability. AI-SDLC v4 defaults to a fast 2-tier model (main ➜ feat/CHG-xxx) and tracks tasks atomically via Git commit trailers.

Streamlined 2-Tier Model Default & Recommended

Features branch directly off main. Developers and AI agents work freely on the feature branch while Git hooks automatically append traceable metadata trailers to every commit.

feat(core): implement task rework calculation

Task-ID: TSK-001
Parent-Ref: CHG-052
Author-Type: agent
AI-Model: Antigravity

💡 Enterprise teams with strict release isolation can still opt into the full 4-tier cascade (main ➜ release ➜ feat ➜ task) seamlessly.

5-minute quickstart

From zero to a governed increment.

Requires Node.js 18+, pnpm 9+ and Git 2.30+.

Bootstrap the repository

npx @aisdlc/cli init

Schemas, templates, policies, 13 agent skills, MCP configs and CI/CD — generated via an interactive wizard.

Scaffold a change from a use case

npx aisdlc change new "Real-Time Alerts" --from UC-STREAM-TELEMETRY

Generates proposal, spec, design, tasks and a handoff.yaml with SHA-256 digests.

Branch with streamlined 2-tier

git checkout -b feat/CHG-002-real-time-alerts

Features branch off main; commit hooks automatically inject Task-ID trailers.

Implement with TDD, then auto-fix pre-flight

npx aisdlc check --fix

Syncs Gherkin to .feature files and refreshes cryptographic digests.

Run all 12 gates & measure rework

npx aisdlc verify all && npx aisdlc kpi pr

Verifies AST quality, security, and computes task-level code churn and rework metrics.
