4-tier Git model

One command. The whole branch cascade.

aisdlc git checkout TSK-001 resolves the release from tasks.md and creates every missing tier — then integrates the change into the canonical baseline when the PR merges.

5-minute quickstart

From zero to a governed increment.

Requires Node.js 18+, pnpm 9+ and Git 2.30+.

Bootstrap the repository

npx @aisdlc/cli init

Schemas, templates, policies, agent skills, MCP configs and CI/CD — via an interactive wizard.

Scaffold a change from a use case

npx aisdlc change new "Real-Time Alerts" --from UC-STREAM-TELEMETRY

Generates proposal, spec, design, tasks and a handoff.yaml with SHA-256 digests.

Branch per task

npx aisdlc git checkout TSK-001

main ➜ release ➜ feat ➜ task, created in cascade.

Implement with TDD, then pre-flight

npx aisdlc check --fix

Syncs Gherkin to .feature files and refreshes digests.

Run all gates & integrate

npx aisdlc verify all && npx aisdlc sdd integrate --auto

Or let CI integrate automatically when the PR merges.
