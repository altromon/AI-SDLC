# ACT-HUMAN-ENGINEER: Ingeniero de Software Humano

## 1. Perfil y Responsabilidad
El Ingeniero de Software Humano actúa como supervisor principal y autor colegiado dentro del ciclo de desarrollo AI-SDLC. Mantiene la soberanía sobre decisiones de arquitectura, aprobación de pull requests y releases a producción.

## 2. Capacidades en el Sistema
- Ejecución de comandos CLI (`aisdlc verify`, `aisdlc report`, `aisdlc sdd`).
- Interacción con agentes de IA mediante entornos IDE (Cursor, VS Code, Antigravity).
- Revisión y aprobación de especificaciones de cambio y planes de implementación.
